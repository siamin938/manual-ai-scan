# 대시보드 화면 재디자인

- 확인된 리비전이 포함된 최신 작업본의 진단 조회, 계산, 권한, 관리자 경로를 유지합니다.
- 상단에 업체 선택, 측정일, 인쇄와 관리자 도구를 모으고 핵심 요약과 상세 분석 전환을 분명하게 표시합니다.
- 핵심 요약은 실제 유효 답변과 확정 등장 수, 기존 근거 기반 첫 확인 항목, 넓은 범위와 상세 조건의 수평 막대로 구성합니다.
- 추가 관찰과 출처는 아래로 접어 보존합니다. 상세 분석은 실제 질문부터 열리고 업체, 출처, 비교, 우선 확인, 방법 및 벤치마크로 묶습니다.
- 접힌 자료도 상세 보고서 인쇄에 포함하고 모바일 글자, 터치 영역, 긴 이름과 표를 대응합니다.
- 관련 테스트와 전체 테스트, 자동 타입 및 빌드 결과, Preview 런타임을 확인합니다. 외부 인증 세션이 없으면 인증 후 시각 검수는 미확인으로 보고합니다.

## 기술 범위
- 화면 및 화면 스타일, 기존 표시 계약 테스트만 변경합니다. 서버, 데이터 모델, DB, 측정 및 게시에는 손대지 않습니다.
- 현재 코드에서 요약 함수 이름은 DashboardSummary이며 사용자가 말씀하신 OwnerSummary 역할을 수행합니다.
