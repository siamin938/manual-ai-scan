# 측정하기 화면 진단 흐름 정리

## 구현 범위
- `runs.index.tsx`의 기존 질문 세트 조회와 측정 생성 호출은 그대로 유지합니다.
- 파일 내부에 이름 접두사와 활성 질문 수를 기준으로 표시 유형을 정하는 작은 순수 helper를 추가합니다.
- 업체별 최신 맞춤 질문 세트를 우선 자동 선택하고, 없으면 조회 순서상 최신 일반 세트를 선택합니다.
- 사용자의 수동 선택은 같은 업체와 같은 다이얼로그 상태에서 유지하고, 업체가 바뀔 때만 다시 자동 선택합니다.
- 질문 세트 목록, 선택 설명, 요약 카드, 안내 문구를 `대표 진단 / 비교 기준 / 질문 세트` 구조로 정리합니다.

## 안전 조건
- 선택된 실제 `questionSetId`, 차단 조건, 활성 질문 조회, 측정권 표시와 차감 계산, 측정 시작 함수는 변경하지 않습니다.
- DB·Edge·parser·측정 생성 로직과 데이터는 변경하지 않고, 새 측정도 실행하지 않습니다.
- Market 등 일반 세트는 24문항으로 확인된 경우에만 `비교 기준`으로 표시합니다.

## 검증
- helper 자동 선택·분류 계약 테스트를 추가하고 기존 고객 측정 테스트를 함께 실행합니다.
- 타입 검사, 빌드, Preview 200을 확인합니다.
- 인증된 읽기 전용 확인이 가능하면 카스페이스 구로점에서 8문항 맞춤 세트 자동 선택과 24문항 기본 세트 수동 선택 표시를 확인합니다.
- Publish/Deploy는 하지 않습니다.
