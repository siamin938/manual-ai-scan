# CHABOIM 유료 진단 v1 상품 정책

상태: 파일럿 판매용 제안안  
범위: 국내 자동차 로컬 업체  
원칙: 측정 결과와 관찰 사실을 판매하며, AI 노출 상승이나 매출 개선을 보장하지 않는다.

## 1. 판매 상품

### A. AI 노출 진단 1회 — 99,000원 (VAT 포함 권장)
- 업체 정보 확인 및 통합 AI 진단 질문 24개 구성
- 24개 질문 1회 측정
- 확정 AI 노출률 / Top3 관찰
- 검색 상황별 관찰
- 함께 관찰된 업체
- 내 업체 관련 검증 출처
- 미노출 질문
- 10초 요약 / 진단 상세
- 결과 해설 1회

### B. 재측정 — 59,000원 (VAT 포함 권장)
- 최초 측정과 동일한 동결 질문 세트 사용
- 동일 조건 비교가 가능한 경우에만 비교 결과 제공
- 맞춤/기준 확정 변화, 새 확정, 이번 미확정 등 현재 Comparison v2 계약 사용
- 질문 세트 변경 후의 측정은 재측정 상품으로 보지 않는다.

### C. 진단 + 2회 재측정 패키지 — 199,000원 (VAT 포함 권장)
- 최초 진단 1회 + 동일 질문 세트 재측정 2회
- 권장 일정: 최초 측정 → 약 30일 후 → 약 60일 후
- 단, 고객이 실제 정보를 수정한 시점에 맞춰 일정은 조정 가능
- 변화는 인과로 단정하지 않고 관찰 차이로만 설명한다.

## 2. 파일럿 정책

초기 10개 업체는 가격을 낮추기보다 **99,000원 진단에 재측정 1회를 포함**하는 방식을 권장한다.

이유:
- 기준 가격 99,000원을 처음부터 시장에 학습시킬 수 있다.
- 재측정을 실제로 사용하게 만들어 Comparison v2의 고객 가치 검증이 가능하다.
- 할인 고객만 모이는 것을 피한다.
- 현재 API 원가는 상품 가격을 결정할 정도로 크지 않고, 실제 비용의 대부분은 온보딩·QA·결과 설명·운영이다.

파일럿 종료 후:
- 신규 진단 99,000원
- 단독 재측정 59,000원
- 3회 패키지 199,000원

## 3. 측정권 지급 정책

현재 측정권은 조직 단위이므로 패키지 총량을 한 번에 지급하지 않는다.

### 단건 진단
결제/승인 확인 → 측정권 1회 지급 → 고객이 측정 시작.

### 재측정 상품
이전 측정 완료 및 비교 가능 조건 확인 → 재측정 직전에 측정권 1회 지급.

### 3회 패키지
최초 1회만 우선 지급한다.  
2차/3차 측정권은 이전 측정 완료 후 일정에 맞춰 각각 지급한다.

운영 메모/Reference Key에는 주문 또는 고객 식별 가능한 내부 키를 기록한다. 동일 Reference Key 재호출은 현재 측정권 지급 RPC의 idempotency를 사용한다.

## 4. 과금·실패 처리

- 시스템 장애로 측정이 정상 완료되지 않은 경우: 고객 책임이 아니라면 측정권 복구 또는 무상 재실행.
- AI 답변에서 업체가 0/24로 나온 경우: 정상 진단 결과이므로 환불 사유가 아니다.
- 고객이 잘못된 업체명·지역·서비스를 제공한 경우: 측정 전 확인을 원칙으로 한다.
- 최초 측정이 시작되면 질문 세트는 비교 일관성을 위해 잠긴다.
- 재측정은 동일 조건 Comparison v2 계약을 충족할 때만 변화 비교를 표시한다.

## 5. 판매 문구

권장:
- "24개 실제 검색 질문으로 AI 답변에서 내 업체가 얼마나 관찰되는지 확인합니다."
- "함께 등장한 업체와 AI 답변이 참고한 출처를 함께 확인합니다."
- "같은 질문으로 다시 측정하면 시간에 따른 관찰 차이를 비교할 수 있습니다."

금지:
- "AI 노출을 올려드립니다."
- "검색 상위 노출을 보장합니다."
- "이 작업을 하면 노출률이 올라갑니다."
- "매출 상승을 보장합니다."

## 6. 아직 만들지 않는 것

파일럿 단계에서는 다음을 새로 개발하지 않는다.
- 자동 정기결제
- 복잡한 구독 플랜
- 무제한 측정
- AI 노출 점수/신뢰도 점수 추가
- 업체별 예외 로직
- 대규모 고객용 멀티모델 자동 추적

10~20건 유료 파일럿에서 실제 사용 패턴을 확인한 뒤 v1.1 범위를 결정한다.
