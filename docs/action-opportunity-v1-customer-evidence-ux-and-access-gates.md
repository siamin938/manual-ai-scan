# Action Opportunity v1.0 — 고객용 근거 표현 간소화 · 접근 권한 QA Gate

상태: **개발 미리보기에서 관리자만 열람 가능한 QA**. 정식 고객 공개 아님.

## 목적
고객의 핵심 요약을 바꾸지 않고 '이번 측정에서 확인할 2가지'의 근거 표시만 간소화한다.
씽카스게러지 안산점 기존 실제 측정에서 다음을 이미 확인했다.

- 기준/넓은 범위 확정 0/8
- 맞춤/상세 조건 확정 3/16
- 페이지 검증 완료 / 관련성 확정 URL 0개 (미검증과 구분)

그 결과에서 **인과관계를 단정하지 않는다.**

## 화면 구성 — 1개 버튼, 중복 안내 제거

핵심 요약의 두 항목 각각:

1. 기존 관찰 제목 (변경하지 않음)
2. 기존 '확인해 보세요' 권고 문장 (변경하지 않음)
3. **'판단 근거 자세히 보기' 버튼 하나**
4. 열면 추가된 관찰 사실·핵심 수치·고지 표시, 같은 버튼은 **'판단 근거 닫기'**로 변경

- 내부 고객 모델의 `recommendedCheck`는 서버에서 유지하되, 요약에 이미 표시되어 있어 확장 영역에서는 반복하지 않음.
- 이전 **두 번째 접기 버튼**은 제거. 자식 프레젠테이션에는 이벤트와 네트워크 호출 없음.
- `관리자 검수 · 이 항목의 근거 미리보기` 중복 링크는 각 항목에서 제거하고 카드 하단의 **접힌 '관리자 상세 검수 도구'**로 이동.
- 기존 관리자 팝업/해당 항목 선택·원본 근거 미리보기 기능은 계속 작동하도록 유지.
- `no-print`: 관리자 검수 버튼, 펼침 영역, 내부 관리자 도구를 인쇄·PDF에서 제외.
- 일반 고객의 공식 화면에는 새 버튼을 아직 표시하지 않음.

## 보안 및 데이터 경계 — 코드 자동 검수

1. 개발 미리보기 표시 조건: 서버로 확인된 `privateV1AdminAllowed` + 현재 세션 사용자·조직·업체·Run
2. 신규 고객용 API: `requireSupabaseAuth` → `organization_members`의 현재 `context.userId` 소속 → 조직 일치하는 `businesses` 활성 고객 업체 → 서버 최신 대표 `fetchEntityFactsV2ReadGateway`와 `expectedRunId` 일치
3. 클라이언트는 수치나 임의 근거를 전송하지 않으며 서버가 동일 Run으로 결정론적 규칙을 재구성
4. React Query 키는 사용자 ID/조직/업체/Run/항목을 모두 포함, 진행 중·실패·타 스코프 응답은 fail-closed
5. 관리자 기존 private API의 `can_view_data_asset_admin_v01` 검증 완화 금지
6. 백엔드 응답은 고객 안전 문구만; 내부 우선순위·score·threshold·비검증 URL·서비스 키 전달 금지
7. `verified_page_zero`는 **검증 완료+관련성 확정 0개**일 때만 제공, 미검증/진행 중을 0개로 승격 금지

검토 당시 Supabase `organization_members`, `businesses`, `measurement_runs`의 authenticated SELECT RLS는
각각 `is_org_member(org_id)`를 사용함을 **읽기 전용 SQL**로 확인했다. 이는 정책 존재 확인이지 다른 계정의 실제 차단 테스트 PASS가 아님.

## QA 매트릭스

| 대상 | 방법 | 기대 결과 | 상태 |
|---|---|---|---|
| 시아민 마케팅 내부 관리자 | 씽카스게러지 안산점, 두 요약 항목 펼치기/닫기 | 한 버튼, 0/8·3/16 및 검증 완료+0개 | 변경 후 수동 확인 필요 |
| 내부 원본 검수 | '관리자 상세 검수 도구' 펼쳐 항목 선택 | 기존 내부 팝업 및 focusedInsight 유지 | 변경 후 수동 확인 필요 |
| 일반 고객/기타 조직 | 현재 해당 계정으로 로그인 | 내부 QA 컨트롤 및 다른 조직 상세 미노출 | **미검증 — 별도 계정 필요** |
| 로그아웃 | 개발 미리보기 로그아웃 후 새로고침 | 근거/이전 조직 데이터 접근 불가 | 미검증 |
| 조직·업체 전환 | 근거를 열어둔 뒤 선택 변경 | 이전 업체 카드·Run 결과 표시되지 않음 | 자동 스코프 테스트 있음 / 브라우저 미검증 |
| 다른 Run 전달 | 이전 완료 Run ID를 최신 API에 제출(테스트) | NOT_AVAILABLE / 다른 Run으로 대체 안 함 | 코드·자동 회귀 검증 |
| 근거 상태 | 검증 `pending`/`not_verified` | 완료된 0개로 오해시키지 않음 | 단위 테스트 검증 |
| 인쇄/PDF | 핵심 요약 인쇄 | 관리자 QA 버튼과 근거 내용 인쇄 제외 | CSS·코드 검사 / 브라우저 미검증 |
| 기존 진단 | 핵심 요약·KPI·상세 분석·측정 기록 | 변함없음 | 회귀 테스트 / UI 재확인 필요 |

일반 고객/타 조직 테스트를 위해 새 사용자를 임의로 등록하거나 접근 권한을 조작하지 않는다.
실제 제2 계정이 없으면 **미검증**으로 유지하고 사용자에게 계정/공개 승인 여부를 확인한다.

## 변경 금지
기존 Entity Facts v2 대표 Run 선택과 확정 판정, 고객 조직·업체 접근 정책, 데이터베이스,
측정권, 재측정, AI 추론, 외부 서버 설정, 크레딧, cron, 운영 Publish 및 PR 병합은 변경하지 않는다.

## 출시 Gate
자동 테스트/빌드 PASS + 실제 관리자 UI QA + 다른 고객 조직/로그아웃 차단 QA 완료 후,
**사용자의 명시 승인**에 따라 별도로 일반 고객 UI 표시 및 운영 Publish를 진행한다.
