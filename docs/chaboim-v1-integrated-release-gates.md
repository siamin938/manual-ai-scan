## 두 가지 데이터 범위는 반드시 분리

| 화면 | 데이터 범위 | 접근 경계 |
| --- | --- | --- |
| 측정 기록 | 사용자가 선택한 **과거의** 완료 Run | 로그인 + 해당 조직 멤버십 + 그 업체 ID + Run 고정 |
| 최신 핵심 요약 | 서버가 현재 선택한 대표 Run | 기존 고객 v2 Read Gateway |
| Action v1 근거 검수 | 최신 대표 Run + 일치하는 요약 항목 | 관리자만 UI 표시 + 사용자 조직/업체 권한 확인 + 서버 Run 일치 |

과거 Run의 경쟁업체나 출처를 최신 Action v1 관찰에 섞지 않습니다.
서로 다른 Run에서 발견된 업체 수, 노출률, 인용 페이지 수를 임의 합산하지 않습니다.
기록 상세 열람에 실패했을 때 최신 Run 데이터를 대신 보여주지 않습니다.
