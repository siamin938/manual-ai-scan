# 차보임 Action Opportunity v1.0 — 관리자 전용 고객 근거 펼침 연결 (Draft QA)

작성 기준: PR #14 `d2ff4bd3b2f8cf6d10a2dc6f621051b389d6059b` 위에 최소 추가.

## 핵심 목표
기존 24문항 헤드라인, KPI 3개, 질문·경쟁업체 카드, 인용 페이지 카드, '이번 측정에서 확인할 2가지', 상세 분석 및 인쇄를 변경하지 않고 **내부 관리자 계정에서만** 요약 항목별 고객용 판단 근거를 클릭해 확인할 수 있도록 연결합니다.

## 추가 UI
- 현재 요약의 각 항목에서 기존 '관리자 검수 · 이 항목의 근거 미리보기' 링크를 **그대로 유지**합니다.
- 해당 항목에 대응하는 고객용 근거가 있을 때 '관리자 검수 · 고객용 근거 펼침 테스트' 링크를 별도 표시합니다.
- 클릭해야만 고객용 읽기 API를 호출하고, 성공할 때만 같은 카드 내에 해당 근거·실제 확인 작업·설명을 표시합니다.
- 로딩 중에는 과거 응답을 표시하지 않고, 근거가 불일치하면 다른 측정 데이터로 대체하지 않습니다.
- 이 연결은 `privateV1AdminAllowed`의 서버 인증 결과가 true인 경우에만 제공됩니다.
- `no-print`로 인쇄·PDF에서 제외됩니다.
- 요약 항목 자체의 관찰 수치와 문구는 변경하지 않습니다.

## 보안·범위
- 고객 전용 API는 기존 PR #14의 `requireSupabaseAuth` → 사용자 RLS 조직 멤버십 → RLS 업체 접근 확인 → 최신 대표 Run 고정 → 현재 표시된 요약 항목의 사실/규칙/검증상태 확인 절차를 유지합니다.
- React Query 키에는 **사용자 ID / 조직 ID / 업체 ID / Run ID / 항목 ID**가 모두 포함됩니다. 새 스코프로 이동 시 이전 항목은 key 변화로 재마운트되고, 응답 스코프가 다르면 표시하지 않습니다.
- 새로운 측정권 차감, AI 측정, DB 변경, 스케줄러·Edge 배포, 추가 점수 생성은 없습니다.
- `verified_page_present`처럼 v1.0에 대응하지 않는 요약 항목은 임의 근거를 생성하지 않습니다.
- 기존 관리자 팝업과 고객용 API는 별개의 경로를 유지합니다. 본 PR은 고객 UI를 일반 고객에게 공개하는 것이 아닙니다.
