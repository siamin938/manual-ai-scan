# 차보임 AI 상세 분석 · 검색 유형 차트 질문 대조 QA

기준: 2026-10-17 · 사용자 요청 · 씽카스게러지 안산점 기존 대표 Run
`8aee5df7-7698-4e38-acdb-313ed72a3ffb`

## 읽기 전용 실제 저장 데이터 대조

- 완료된 고객 진단 24문항 · 질문 작성 시 저장한 intentType 8개 × 3문항
- 각 유형의 유효 응답이 3개인 이번 측정에서:
  - 지역·접근성(local) **1/3**: "안산에서 PPF 맡기기 편한 업체 몇 곳 알려줘"
  - 추천(recommendation) **1/3**: "안산에서 PPF 맡길 만한 업체 추천해줘"
  - 전문성·신뢰(trust) **1/3**: "안산에서 PPF 작업 경험이 많은 업체 몇 곳 알려줘"
  - 비교(comparison) 0/3
  - 탐색·발견(discovery) 0/3
  - 가격·가성비(price_value) 0/3
  - 후기·평판(review_quality) 0/3
  - 서비스·작업(service) 0/3
- 합계 **3/24**로 기존 확정 노출 KPI와 정확히 일치.
- 같은 표현이 다른 목적에 포함되기도 함: 예를 들어
  "안산에서 PPF 잘하는 곳 알려줘"는 저장 시 **service**로 분류됨.
  이는 노출 집계 오류가 아니라 검색 목적 이름의 의미가 겹칠 수 있다는 UX 해석 문제.

## 이 커밋의 최소 UI 개선

- 기존 그래프 수치/색상/의미와 v2 판정·측정·질문 intent 데이터는 **변경 없음**.
- 서술을 "비슷한 질문을 AI가 다시 묶었다"는 인상을 주지 않도록
  **"질문을 만들 때 지정한 검색 목적별 분류"**라고 정확하게 안내.
- `1/3`은 3개 질문 유형의 **유효 답변 3개 중 확정 노출 1개**임을 명시.
- 그래프 아래 `검색 상황별 실제 질문 24개 확인` 펼침 도구를 추가.
  처음에는 접혀 있으며, 누르면 각 intentType의 정확한 질문 3개와
  "확정 노출 / 추가 확인 / 확정 노출 없음"을 보여줌.
- 질문목록은 **동일 대표 Run의 서버 인증 v2 DTO** `questionAreas`에서만 가져옴.
  `questionGroups`의 questionCount, validCount, confirmedMentionCount,
  unresolvedTargetCount와 질문별 합계가 모두 일치할 때만 항목 표시.
  맞지 않으면 질문 내역을 임의로 채우지 않고 "검증 불가" 메시지 표시.
- 인쇄/PDF 변경 최소화를 위해 보조 펼침을 `no-print`로 제외.
- 기존 엔진, AI 재측정, DB/권한/크레딧/고객 공개 영향 없음.

## QA 범위

자동 회귀 검증: 8종×3문항·3/24, 실제 저장된 3개의 질문 예시,
비슷한 표현 재분류 금지, Run의 그룹/질문 숫자 일치 검사,
오염·중복/유효 0건/추가 확인 상태, 기존 그래프 바와 상세 화면 유지.
