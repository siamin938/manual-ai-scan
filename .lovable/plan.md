# 측정 목록·상세 진단 유형 표시 통일

## 구현 범위
- 측정 목록 조회에 `question_set_id`와 과거 비활성 질문 세트 이름 조회를 추가하고, 기존 분류 helper로 각 실행을 `맞춤 진단 / 기본 진단 / 일반 측정`으로 표시합니다.
- 질문 수는 `N문항`으로 표시하며 상태·완료·실패·시간과 새 측정 Dialog는 유지합니다.
- 측정 상세에서 해당 질문 세트 이름을 읽어 같은 분류 helper를 재사용하고, 상단에 유형·질문 수·질문 세트명과 유형별 설명을 표시합니다.
- 과거 맞춤 측정은 유형만 맞춤 진단으로 표시하고, 현재 대표라고 단정하지 않습니다.

## 안전 조건
- 기존 결과 요약, 노출률, 업체·출처·응답 계산과 저장된 답변 다시 분석 버튼 로직은 변경하지 않습니다.
- 측정 생성, 측정권·비용·중복 방지, DB·Edge·parser와 데이터는 변경하지 않습니다.
- 맞춤 진단과 기본 진단 사이 상승·하락 비교 문구를 추가하지 않습니다.

## 검증
- 기존 질문 세트 선택 테스트를 표시 문구와 상세 helper 재사용 계약으로 보강하고 고객 측정 테스트를 함께 실행합니다.
- 카스페이스 4개 실행의 질문 세트명·질문 수·표시 유형을 읽기 전용으로 확인합니다.
- 타입 검사, 관련 테스트, 빌드, Preview `/runs` 200을 확인합니다.
- 실제 측정·재분석 및 Publish/Deploy는 실행하지 않습니다.
