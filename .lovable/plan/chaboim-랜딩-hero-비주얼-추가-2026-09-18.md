# CHABOIM 랜딩 Hero 비주얼 추가

## 구현 범위
- 기존 Grand Tourer의 그래파이트·코발트 디자인 언어에 맞는 와이드 정적 이미지를 생성합니다.
- 랜딩 첫 화면의 왼쪽 카피와 CTA는 그대로 유지하고, 오른쪽 약 45~50% 영역에 이미지를 크게 배치합니다.
- 기존 `AI 노출 분석 흐름`은 삭제하지 않고 Hero 바로 아래의 보조 영역으로 이동해 이미지와 경쟁하지 않게 합니다.
- 모바일에서는 이미지가 카피 아래로 내려가며 차량이 온전히 보이도록 비율과 위치를 조정합니다.

## 변경 파일
- `src/routes/index.tsx`
- `src/assets/` 아래 새 정적 이미지 1개

## 시각 방향
- 밝은 쿨 화이트 배경, 짙은 그래파이트 럭셔리 세단, 절제된 코발트 데이터 라인과 분석 모티프
- 사진과 CGI가 결합된 프리미엄 에디토리얼 톤
- 사람, 로고, 읽을 수 있는 텍스트, 네온·레이싱·튜닝 광고 표현 제외
- 과한 둥근 모서리나 그림자 없이 얇은 구분선 중심으로 구성

## 보존 사항
- 랜딩 카피, CTA 의미, 메뉴, 링크와 기존 분석 흐름 콘텐츠를 유지합니다.
- 로그인 후 화면, 앱 로직, 데이터 계약, 스타일 토큰은 변경하지 않습니다.
- publish/deploy는 진행하지 않습니다.

## 검증
- 데스크톱과 모바일 Preview에서 이미지 프레이밍과 콘텐츠 겹침을 확인합니다.
- `bunx tsc --noEmit`, `bunx vitest run`, `bun run build`, `git diff --check`를 실행합니다.
- 변경 범위가 랜딩 표현과 새 정적 이미지에만 있는지 확인합니다.
