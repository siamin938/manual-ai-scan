# Dashboard 막대 차트 시각화 개선

## 목표
현재 Dashboard의 긴 진행 막대를 기존 측정값을 그대로 사용하는 간결한 가로 막대 차트로 교체합니다.

## 변경 범위
- `src/routes/_authenticated/dashboard.tsx`의 표시 코드만 수정합니다.
- 이미 설치된 Recharts와 `ResponsiveContainer`를 사용합니다.
- 필요하지 않으면 별도 파일이나 전역 스타일은 추가하지 않습니다.

## 구현 내용
1. 최근 측정 결과
   - 확정 노출, 추가 확인, 노출 미확인을 한 개의 가로 누적 막대로 표시합니다.
   - 막대 아래에는 기존 건수와 비율을 접근 가능한 텍스트로 유지합니다.
2. 검색 상황
   - 행별 진행 막대를 없애고, 모든 검색 상황을 한 차트에서 비교합니다.
   - 각 행에 기존 `intentLabel()`과 확정/추가 확인/미확인 건수를 표시하고 단순 툴팁을 제공합니다.
3. 시장 벤치마크
   - 출처 그룹별 카드 안 진행 막대를 없애고, 기존 `highEntitySharePct`를 한 가로 막대 차트로 표시합니다.
   - 연결 여부, 관찰 건수, 사이트 정보, 카테고리 참고 정보와 인과관계 주의 문구는 유지합니다.

## 보존 사항
- 서버 요청, Supabase, DB, Edge Function, DTO와 데이터 계약은 변경하지 않습니다.
- Action Opportunity/Evidence 및 다른 Dashboard 섹션의 계산과 기능은 변경하지 않습니다.
- 새 분석값이나 점수는 만들지 않으며, 기존 값의 화면 표현만 바꿉니다.
- Publish/Deploy는 하지 않습니다.

## 검증
- TypeScript 검사와 앱 빌드를 확인합니다.
- Preview 재빌드 상태와 데스크톱·모바일 화면에서 차트 가독성, 텍스트 접근성, 오류 여부를 확인합니다.
