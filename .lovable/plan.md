# 질문 화면 현재 세트 기준 요약 정리

## 변경 범위
- `src/routes/_authenticated/questions.tsx` 한 파일만 수정합니다.
- 기존 질문 세트 선택값인 `setId`를 요약 카드, 검색 상황 집계, 저장된 질문 목록이 함께 사용하도록 연결합니다.
- 업체를 선택했지만 세트를 아직 고르지 않은 경우에는 기존 목록의 첫 번째 세트(현재 정렬상 최신 생성 세트)를 최소 기본값으로 선택합니다. 사용자가 선택을 바꾸거나 새 세트를 저장하면 기존 `setSetId` 흐름을 그대로 따릅니다.

## 화면 변경
- 전체 세트 합산 조회와 집계를 요약에서 제거하고, 선택된 세트의 활성 질문만 집계합니다.
- KPI를 `현재 질문 세트` 이름, `질문 수`, `검색 상황`으로 변경합니다.
- 긴 세트 이름은 한 줄 생략 표시하고 전체 이름은 마우스를 올렸을 때 확인할 수 있게 합니다.
- `검색 상황별 질문 수`는 선택 세트에 실제 존재하는 활성 질문만 표시하며, 0개인 상황은 숨깁니다.
- 운영자 버튼을 작은 `운영자 도구` muted 영역 안으로 옮기되 기존 권한 조건과 실행 동작은 유지합니다.
- 맞춤 진단 카드의 보조 문구만 요청하신 고객용 표현으로 바꿉니다.

## 보존 사항
- 맞춤/기본 질문 생성 및 저장, 질문 수정·잠금·활성 상태, 측정 기능은 변경하지 않습니다.
- Supabase, DB, Edge Function, parser, API, 기존 데이터와 배포는 건드리지 않습니다.

## 검증
- 타입 검사, 맞춤 질문 관련 테스트, 빌드를 확인합니다.
- Preview 200 응답과 로그인 가능한 세션 여부를 확인합니다.
- 세션 접근이 가능하면 카스페이스 구로점에서 맞춤 8문항 및 기본 24문항 세트를 각각 선택해 KPI와 검색 상황별 집계를 확인합니다. 인증 세션이 없으면 코드·쿼리 기준 검증 결과와 확인 제한을 구분해 보고합니다.
